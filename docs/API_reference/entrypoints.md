title: Entrypoints
---

Entrypoints are functions that can be directly called to perform a high-level task. Each of the
entrypoints listed below can also be called as a command line script; the scripts accept arguments
that are passed straight through to these functions.

For flag-by-flag documentation of the command line form, including which arguments are required, see
[Command Line Usage](../command_line_usage/index.md).
